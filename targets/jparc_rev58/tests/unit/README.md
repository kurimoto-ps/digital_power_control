# ホスト単体・通信試験

リポジトリ直下で `python3 -m unittest discover -s targets/jparc_rev58/tests/unit -v`。
Python標準ライブラリとホストCコンパイラ `cc`（`CC`で変更可）を使用する。
実際のCコマンド処理を一時ディレクトリへコンパイルし、SPI仕様モデルと接続する。
テストベクトル、入力拒否、SPI失敗、読戻し不一致、FPGAエラー、TCP分割応答、
PC自動試験、WRITE_COUNT周回を確認する。Zephyrネットワーク／実機／RTL試験ではない。

ADC検査は仕様のCRC既知ベクトル、3系統の順序入替、通番周回、分割入力、再同期、
値違い／重複／欠落と、ホストの結果検査・TCP分割JSON応答を含む。
SPI4にはv1.3互換、CONTROL clear bit、DAC完了ポーリングの模擬試験を追加した。

お客様用スクリプトは符号境界・換算電圧、入力更新なし、フレーム再開始、
初期化の書込み範囲、DAC statusの読取り専用動作とset対象アドレスを模擬検証する。

DAC電圧指令は±10 V端点、半LSB丸め、全65,536コードの往復変換、
CN3～CN18の指定、範囲外・NaN・無限大の通信前拒否も検証する。

FPGA v2は実Cデコーダの48バイト既知ベクトル、10,000フレームの連続分割入力、
CRC破損・再同期・予約bit・フレーム欠落・通番周回、ADC24 fresh/age整合性、
符号付きADC16を検査する。ホストAPPLYの拒否・タイムアウト・適用ID/値不一致、
光入力の期待値範囲、v2 SPI4マスク読戻し、ADC連動中の手動DAC拒否も検証する。
2026-11-07: 計42件成功。Zephyr DMA割込みと実機SPI1波形はホスト試験対象外。

PLC/UART試験は実Cコマンドパーサの範囲・形式チェックと、ホストの32点ワークフロー、
誤配線相当の入力、途中中断時の出力復帰、通信断で復帰未確認となる場合、UART受信エラーを検証する。
GPIO・UARTの実電気特性は試験対象外。配置検査では32 GPIOの順序・J8配線・ピン重複とUART8のAF8／TX-RX入替を照合する。
2026-11-07 PLC/UART追加後：計49件成功、rev58全8プロファイルのビルド・配置検査成功。
