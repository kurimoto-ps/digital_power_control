Feedback control
################

このディレクトリには、顧客が製品に合わせて調整するPI制御を実装しています。
PWM出力を2段RCフィルタ（R1=R2=4.7 kOhm、C1=C2=1 uF）経由でA0へ戻し、
ADC電圧が目標値へ一致するようhigh-side PWM dutyを調整します。各RC段の時定数は
4.7 ms、直流ゲインは1です。

``FEEDBACK`` モードでは ``SET`` の第2引数がADC目標値（フルスケール比）です。
例えば ``SET 20000 50 0`` は20 kHz PWM、ADC目標50%（約1.65 V）を指定します。
``GET`` の ``target`` は目標値、``duty`` はPIが計算した実際のPWM dutyです。

PI制御
******

制御周期はADCの固定10 kHzサンプル周期（100 us）です。初期ゲインは次の値です。

* 比例ゲイン ``Kp = 0.5``
* 積分ゲイン ``Ki = 50 /s``
* 出力範囲 ``0..100%``
* 条件付き積分によるanti-windup

PI演算は整数Q16固定小数点で実装され、DMA割り込み内ではなくM4の専用feedback
スレッドから、各ADCサンプルにつき1回だけ呼ばれます。DMA、割り込み、固定10 kHz
ADCトリガ処理は ``control_core/platform`` に分離されています。

ゲインを変更する場合は ``feedback_control.c`` の ``PI_KP_MILLI`` と
``PI_KI_PER_SECOND_MILLI`` を調整します。実際の電源回路へ接続する前に、対象プラントで
安定性、応答、duty上限、過電流保護を検証してください。処理は制御周期内に必ず完了させ、
sleep、ネットワークアクセス、動的メモリ確保、無期限待機を避けてください。
